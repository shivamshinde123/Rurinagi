Privacy Policy

Effective October 11, 2026

Rurinagi is a local-first Windows focus and planning application published by Shivam D Shinde. This policy explains what the application and this website do with information.

Information in the desktop application

Rurinagi stores the tasks, projects, notes, settings, and focus-session history you enter in a SQLite database on your Windows device. Rurinagi does not require an account and does not transmit this information to the publisher, an analytics provider, or an advertising service.

Optional Windows features

Desktop notifications and starting Rurinagi when you sign in to Windows are optional and disabled until you select them. You can change either choice in Settings. Windows may also expose system-level controls for these features.

Exports and backups

When you export JSON or create a database backup, you choose where the file is saved. Those files are outside Rurinagi's control. Protect or delete them using Windows and any backup or synchronization software you choose.

Deletion and uninstalling

You can delete individual tasks and focus records or use Clear all data in Settings. Clearing data permanently resets the local Rurinagi database after confirmation. Before uninstalling, use Clear all data if you also want to remove the information stored in the application data directory; uninstallers can leave user-created data behind.

Website and cookies

The Rurinagi website does not set application cookies, run analytics, show advertising, or contain data-collection forms. It is hosted on GitHub Pages, so GitHub may process ordinary connection information under the GitHub Privacy Statement.

Third-party software

Rurinagi includes open-source runtime components such as Electron and React. They run as part of the installed application; Rurinagi does not use them to send analytics or advertising data. License notices are distributed with the application and source materials.

Children

Rurinagi is a general productivity tool and is not designed to collect personal information from children. Because there is no account or publisher-operated data collection, the application does not ask for a user's age.

Changes and contact

Material changes will be reflected here with a revised effective date. Privacy questions can be directed to the publisher through the Shivam D Shinde GitHub profile.
